# Knowledge base

This vault captures findings and understanding built up while discussing
papers with Claude Code. It's meant to be opened directly as an Obsidian
vault.

- `articles/` -- one note per paper discussed
- `concepts/` -- one note per idea that recurs across papers or findings
- `findings/` -- one note per distinct insight reached in a session

Everything here is written by Claude Code only with your approval, at the
end of a paper-discussion thread. The full convention (note types,
approval gate, cleanup rules) lives in `.claude/CLAUDE.md`'s "Obsidian
research knowledge base" section, not in this file.
