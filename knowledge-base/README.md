# Knowledge base

This vault captures findings and understanding built up while discussing
papers with Claude Code. It's meant to be opened directly as an Obsidian
vault — point Obsidian at this `knowledge-base/` folder, not the repo root.

Starts empty on purpose: no folder structure or note taxonomy is imposed
upfront. How things get organized emerges from how you actually want to
use it.

Everything here is written by Claude Code only with your approval — it
drafts, shows you the draft, and writes nothing until you say yes. Nothing
is ever saved silently.

Notes reach the vault two ways. The usual one is an offer at the end of a
paper-discussion thread, when you signal you're done or the conversation
moves on. The other is the `onboarding` skill, run once when a project is
first set up: it discusses what the project is actually about and offers to
record a note about it, which is often this vault's first real content.
Same approval gate either way, and the filename is proposed to you rather
than imposed.

The full convention lives in `CLAUDE.md`'s "Obsidian research knowledge
base" section, not in this file.
